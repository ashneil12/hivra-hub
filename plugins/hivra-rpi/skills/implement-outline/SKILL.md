The first mate runs this phase.

Write a structure outline the crew can build from: the modules to touch, the order of the work, and the checks that show it is done. The outline follows the design document. It does not replace the crew's own review or the done gates.

Building after this outline uses the normal crew path. Do not skip those gates from this phase.
