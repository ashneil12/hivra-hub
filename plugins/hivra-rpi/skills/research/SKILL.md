The first mate runs this phase.

Answer the research questions with facts about the code as it is. Cite the file for each fact. When a document and the code disagree about how the code behaves today, the code wins.

Do not propose a design. Do not change code. Searching can use a cheaper model. Judgment about what the facts mean waits for the design phase.
