# WP-129: A cheap text-generation model for titles, commits and PR text

| Wave | Size | Depends on | Grok OK |
| --- | --- | --- | --- |
| T3 parity | S | none | yes |


## Goal

Titles, commit messages, PR text, branch names and similar short text are generated by a dedicated, cheaper text-generation setting, not by spinning up the project's coding CLI. If no text-generation model is configured, today's behaviour remains the fallback.

## Why

T3 is moving this to a first-class setting in nightly 0.1.8 ([docs/user/text-generation.md](https://github.com/pingdotgg/t3code/blob/e85e0094dd4617a1eada1ad7961f2132a79e67b2/docs/user/text-generation.md)). Hivra's `textHarness.ts` starts a coding agent for the same job, which is slow and burns a paid coding turn.

## Keys saved before this change

Keys saved before this change must be re-saved under Other models before quick pick, memory, the context window and routed sessions use them. A key is used only at the provider, model and address it was saved with; a key saved before that binding was recorded is not sent anywhere until it is saved again. The Other models list and the memory model picker show each saved address, so the person can check it.

## Read first

- Hivra: `textHarness.ts` and every caller (commit, PR, title, branch).
- T3 behaviour (ideas only): [docs/user/text-generation.md](https://github.com/pingdotgg/t3code/blob/e85e0094dd4617a1eada1ad7961f2132a79e67b2/docs/user/text-generation.md).

## Build

1. A setting for a text-generation provider and model (optional). Validated on read; missing means 'use today's coding-CLI path'. Tests for the setting and the migration.
2. A narrow client that asks that model for short text and returns a string or a clear error. No tool use, no repo writes. Tests with a stubbed port.
3. Wire title, commit, PR and branch generators to try the text-generation client first, then fall back. Tests that the fallback still runs when the setting is empty or the client errors.
4. A Settings row in plain words. Browser spec.

## Done when

- [ ] Configured text generation is used for titles and commit or PR text.
- [ ] With no setting, today's path is unchanged.
- [ ] The text-generation client cannot write to the repo.
